# Operations and units

All operations are strict objects; unknown fields fail. Plan max 1000 changed note objects. Consecutive operations apply to a prospective model (insert then transform works). section is free JSON phrase metadata, NOT an automatic range guard. Use section:{name,start_beat,end_beat,evidence_refs:[...],rationale,hand_plan} to preserve design in sidecar.

- create_line: {type,id,name,role,anchor_id?,x?,y?,rotation?,opacity?,speed?}. Role playing_anchor/note_carrier/decorative; carrier requires existing playing anchor ID. Main ID is 'main'. Public x/y logical centered fractions; hidden carrier opacity 0 can transport visible notes. Decorative line cannot own scoring notes.
- annotate_line: {type,line_id,role,anchor_id?,annotation?}. Imports leave source roles unclassified. Static note counts cannot determine active playing loci.
- insert_notes: {type,line_id,notes:[{kind,beat,x,side?,speed?,duration?,annotation?,id?}]}. kinds tap/drag/hold/flick. Beat exact string/integer/triple. side above(default)/below. speed positive, default 1. Hold requires positive duration in beats. annotation arbitrary bounded JSON e.g voice/hand/finger/gesture/rationale.
- insert_pattern: {type,line_id,pattern,lane_x,order?,kind?,side?,speed?,duration?,annotation?,start?,count?,step?,beats?}. Either start/count/step OR exact strictly increasing beats array. stairs cycles editable order; alternating needs 2 stations; chord creates all stations per onset; drag_path traverses stations with continuous interpolated contour. No one finger per drag inference. kind default tap except drag_path default drag. Uniform 32 onsets at step 1/4 fill 8 beats; last is start+31/4.
- transform_notes: {type,line_id,start,end,mirror?,shift?,scale?,speed_multiplier?,beat_shift?,kind?,side?}. Head-selected half-open musical beats [start,end). Mirror logical x; shifts/scales x preserve other fields. Hold duration preserved across tempo changes. kind conversion tap/drag/flick explicitly removes hold duration; creating hold requires insert_notes with duration.
- set_effect: {type,line_id,channel,start,end,a,b?,easing?,replace?}. channels x/y/rotation/opacity/speed. Start/end musical beats; a/b units match channel. Alpha 0..1; line speed official units. linear easing only; speed must constant. Overlap refused unless replace:true, which splits source intervals and restores prior inherited state after range. Carrier motion should resolve on main playing locus; decorative effects do not create contacts.

Executable discriminated operation schemas are returned in tools/list and phigros-authoring://schemas/v1. Runtime semantic checks enforce rational relations, positive duration, valid order indices and event precision. Tool errors give rejected field/condition; no partial offline edits occur. source official metadata is retained; imported untouched chart exports source semantically unchanged. Edited source events with overlapping ambiguous tracks cannot export silently.

- update_note: {type,line_id,id,note}. Complete replacement note, preserving stable ID and retained unknown source fields. Retrieve the exact note by bounded read first.
- delete_notes: {type,line_id,ids}. Delete named stable IDs only; unknown IDs fail the entire transaction.
- move_note: {type,line_id,id,target_line_id,x}. Move an existing note with its ID to another scoring line. Explicit target-local x avoids implicit world-position guesses; carrier convergence and hold stability remain checked.

`authoring_plan_phrase` selects a cached single-phrase evidence record and compact motif config. Default four finger labels are hypotheses for a multifinger arrangement, not a claim of ergonomic proof. Configure finger_order as priority; allowed_fingers is a hard permitted-label list; hold_fingers/drag_fingers assign the sustained and travelling roles within it (defaults choose permitted labels). A one sustained-contact plus other-hand answer recipe can use allowed_fingers:[L_index,R_index], hold_fingers:[L_index], hold_mode:alternating, finger_order:[R_index]; paired hold modes require two hold labels or fail with repair advice; stored holds/flicks and grouped drag gestures carry release guards across phrases. Motif strings label semantic intent; configuration fields actually choose expansion rules. `evidence_import` loads local portable records {source_sha256,settings,producer,analysis} without placing analysis arrays in model-facing arguments. No hidden audio processing occurs.

- annotate_notes: {type,line_id,annotation_patch,ids? OR start/end?}. Shallow-merge annotation fields into stable-ID selected notes or half-open head range; preserve scoring fields. Explicit empty range selection changes no notes. Unknown IDs reject transaction. Patch <=16KiB; per-plan1000 note-action limit still applies.
